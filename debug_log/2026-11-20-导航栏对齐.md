# 导航栏图标与文字不在同一水平线

## 2026-11-20 19:52

- **文件**：`_sass/_base.scss`
- **改动**：新增 1 条媒体查询规则，共 7 行（含 2 行注释）

### 触发问题

首页导航栏（右上角）的 dark mode 图标明显低于 `Home / Publication / Blog / CV` 等文字项，
看起来"掉"到下面一行；其余项目之间对齐正常。

### 原因分析

1. `_sass/_themes.scss` 里三个可见图标（`#light-toggle-system` / `#light-toggle-dark` /
   `#light-toggle-light`）都带了上游的撑高 hack：

   ```scss
   padding-left: 5px;
   padding-top: 17px;
   padding-bottom: 17px;
   ```

   该元素总高约 53px，而普通 `.nav-link` 高约 40px。

2. `.navbar-nav`（Bootstrap flex 容器）默认 `align-items: stretch`，
   所有 `<li>` 被拉伸到最高项（53px）；`<a class="nav-link">` 也在顶部对齐，
   于是文字整体偏上、图标被 17px 上内边距往下推，两者错开约 5.5px。

   实测（截图像素扫描，y 为行号，越小越靠上）：

   | 元素 | top | bottom | 中心 |
   |---|---|---|---|
   | 文字 Home | 16 | 27 | 21.5 |
   | 太阳图标 | 21 | 33 | 27.0 |

### 改动做法

在 `_sass/_base.scss` 的 `#light-toggle, #search-toggle` 规则前插入：

```scss
// Center nav items on one line (the theme icon is taller due to its 17px padding).
// Only for the horizontal bar; the collapsed mobile menu is left untouched.
@media (min-width: 576px) {
  .navbar-nav {
    align-items: center;
  }
}
```

选择说明：

- 只加 `align-items: center`，不去动 `_themes.scss` 的 17px 内边距 —— 该内边距实际在撑导航栏高度，
  删掉会让导航栏变矮，改动面更大。
- 用 `@media (min-width: 576px)`（Bootstrap `sm`）限定，避免移动端折叠菜单（竖排）
  被 `align-items: center` 改成水平居中。

### 验证方式

```bash
# 1) 确认已编译进产物
grep -o "navbar-nav{[^}]*}" _site/assets/css/main.css
# → navbar-nav{align-items:center}

# 2) 截图像素扫描（headless Chrome + 自写 PNG 解码脚本）
#    before: 文字 16-27 / 图标 21-33
#    after : 文字 21-32 / 图标 21-33  → 误差 0.5px
```

- `/` 与 `/publications/` 均对齐；700px 宽（仍为横排）同样对齐。
- 导航栏高度未变，移动端折叠菜单样式未受影响。

### 影响面 / 回滚

- 影响：`min-width: 576px` 下所有页面的导航项垂直居中；纯 CSS，无模板改动。
- 仍保留上游的 17px 内边距 hack，故导航栏高度与原版一致。
- 回滚：删除该 `@media` 块即可，其余文件无需处理。
