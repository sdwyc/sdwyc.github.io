## 08:40 — 在 Ubuntu 24.04 + Ruby 3.2 下重新解析依赖

- **文件**：`Gemfile.lock`
- **做法**：临时容器（Ubuntu 24.04 + `ruby`/`ruby-dev` + `gem install bundler -v 2.5.22`）中

  其余 94 个 gem 版本不变；`ssrf_filter` 不再被引入（新 lock 中 `feedjira 4.0.4` 的实际依赖为

## 08:50 — 重写 Dockerfile：系统与工具链版本固定

- **文件**：`Dockerfile`（整篇重写）
- **做法**：
  1. `ARG UBUNTU_VERSION=24.04` → `FROM ubuntu:${UBUNTU_VERSION}`，系统版本一个变量控制；
  2. 三个版本变量 + 构建期断言，版本漂移直接失败而不是悄悄跑偏：
     ```
     ARG RUBY_VERSION_REQUIRED=3.2
     ARG BUNDLER_VERSION=2.5.22
     ARG NODE_VERSION_REQUIRED=18
     ruby -v | grep -q "ruby ${RUBY_VERSION_REQUIRED}\." || exit 1
     node -v | grep -q "^v${NODE_VERSION_REQUIRED}\."    || exit 1
     convert -list format | grep -q "WEBP"               || exit 1
     ```
  3. apt 安装 `ruby ruby-dev build-essential zlib1g-dev libssl-dev libyaml-dev libffi-dev
     imagemagick nodejs ca-certificates curl git procps`，不再依赖 ruby 官方镜像预置；
  4. `gem install bundler -v ${BUNDLER_VERSION}` 显式固定 Bundler；
  5. `COPY Gemfile* ./` + `bundle install` 严格按 lock 安装，构建期零解析；
  6. 移除双阶段 node 镜像（Ubuntu 的 `nodejs` 包已足够，且版本可断言）。
- **踩坑**：首行 `# syntax=docker/dockerfile:1.7` 会去 Docker Hub 拉前端镜像，
  当前 `auth.docker.io` 返回 502 → 删除该指令（已不使用 cache mount，无需它）。
- **验证**：构建日志
  ```
  ruby 3.2.3 (2024-01-18) [aarch64-linux-gnu]
  v18.19.1
  Bundler version 2.5.22
  Bundle complete! 22 Gemfile dependencies, 96 gems now installed.
  ```

## 09:00 — lock 纳入版本控制 + 补齐多平台

- **文件**：`.gitignore`、`Gemfile.lock`
- **触发问题**：`.gitignore` 里 `Gemfile.lock` 被忽略 → 版本根本没被"固定"，
  每次全新克隆都会重新解析（可能拉回不兼容版本）；且原 lock 只有 `aarch64-linux-gnu` 一个平台，
  x86_64 CI 或 Intel Mac 上会因平台缺失而重新解析。
- **改动做法**：
  - `.gitignore` 中注释掉 `Gemfile.lock` 一行（改为纳入版本控制）；
  - 容器内执行 `bundle lock --add-platform x86_64-linux aarch64-linux arm64-darwin x86_64-darwin ruby`。
- **验证**：`PLATFORMS` 现为 6 项（aarch64-linux / aarch64-linux-gnu / arm64-darwin / ruby /
  x86_64-darwin / x86_64-linux），`BUNDLED WITH 2.5.22` 与 Dockerfile 中 `BUNDLER_VERSION` 一致。
- **影响面 / 回滚**：改动 Gemfile 后必须同步 `bundle lock`，否则 lock 与 Gemfile 不一致；
  回滚即恢复 `.gitignore` 中的 `Gemfile.lock`。
